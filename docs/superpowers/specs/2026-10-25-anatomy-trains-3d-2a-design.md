## 1. 目標與範圍

把肩帶原型擴充到全身的軀幹、頸部與下肢，並加入「痠痛點」：

1. **拆解**：沿用第一階段（分層、隱藏、半透明 10%、拉出、爆炸圖、隱藏清單）。
2. **連動**：新增脊椎、骨盆、下肢的骨段與六種預設姿勢；肩膀滑桿可兩側一起或只調一側。
3. **痠痛點**：在肌肉上標出常見痠痛點（激痛點），說明卡寫出痠痛位置、轉移痛範圍，以及鎖短、鎖長時痠痛的意義。
4. **中文說明**：新增約 120 條肌肉，全部 148 條都有痠痛點與轉移痛欄位。

## 3. 資料

- 沿用 Z-Anatomy 肌肉與骨骼 FBX。肌肉保留 35% 三角面、骨頭保留 25%。
- **骨頭的骨段歸屬**由 `BONE_SEGMENTS` 依序比對（先比到的優先），例如股骨先歸大腿，「下肢自由部骨」其餘才歸足部。
- **部件的骨段**不再手寫，改由附著骨頭自動決定。

資料上的特殊處理：

| 情況 | 處理 |
|---|---|
| 左側頸髂肋肌的網格沒有 `.l` 後綴 | `zNames: { l: 'Iliocostalis colli muscle' }` |
| 腓腸肌、比目魚肌、伸趾長肌、肛門外括約肌的網格沒有延伸到骨頭（肌腱沒有建模） | 放寬 `maxGap`（腓腸肌 18、比目魚肌 10、伸趾長肌 5、肛門外括約肌 4 公分），遠端以跟骨等實際止點為準 |
| 舌骨懸吊在下頷與胸骨之間 | 舌骨與甲狀軟骨隨頭部移動。若固定在頸段，舌骨上肌群會算出 +121% 這種不合理的變化 |
| 橫膈是穹頂形 | 不計算長度（以灰色顯示），和筋膜、肌腱相同 |
| 兩端附著骨頭重疊、兩端點重合 | 端點修整時退回附著區平均位置；長度變化在兩端距離 < 0.5 公分時視為 0 |

## 4. 骨架

24 個骨段：

- 中線：`pelvis`、`L5`–`L1`、`thoraxLow`（T9–T12 與第 9–12 肋）、`thoraxMid`（T5–T8、第 5–8 肋、胸骨體、劍突）、`thoraxUp`（T1–T4、第 1–4 肋、胸骨柄）、`neckLow`（C5–C7）、`neckUp`（C1–C4）、`head`（頭骨、下頷骨、舌骨、甲狀軟骨）
- 左右各一：`clavicle`、`scapula`、`arm`、`femur`、`shank`（脛、腓骨、髕骨）、`foot`

轉軸（轉檔時估算，寫入 `meta.joints`）：

- 每個脊椎骨段：該段最下方那節椎體（最前方 2 公分）的下緣；頭段在寰椎上緣。
- 髖關節：股骨最內上方一帶（約 3 公分內）做球面擬合。

### 姿勢參數（−1…+1）

| 參數 | 分左右 | ±1 時 | 說明 |
|---|---|---|---|
| `headForward` | 否 | 下頸段前屈 25°、頭段後仰 22° | 頭前傾 |
| `thoracicFlexion` | 否 | 胸椎屈曲 30°（下、中、上段 3:4:3） | 頸、頭各補回一半，視線維持水平 |
| `pelvicTilt` | 否 | 骨盆繞兩側髖關節連線轉 18° | 腰椎五節平均反向轉回，胸廓維持直立；雙腳不動 |
| `pelvicObliquity` | 否 | 骨盆繞長腳側髖關節側傾 8° | 正值＝左側下降（左腳短）；短腳那側整條腿隨髖關節下移；腰椎五節平均側彎代償 |
| `scapProtraction`、`scapElevation`、`shoulderRotation` | 是 | 同第一階段 | 肩帶在胸廓上段的座標系計算 |

**骨盆的 18°、8° 是示範用的放大幅度**：一般前傾約 12°、長短腳 4° 時，髂肌、膕旁肌、腰方肌的變化都不到 3%，顏色看不出來。頁面與使用說明都會註明。

### 預設姿勢（8 個）

中立、圓肩（肩胛前伸 0.8、內旋 0.6）、頭前傾、胸椎駝背、骨盆前傾、骨盆後傾、高低肩（右肩上提 0.7、左肩下壓 0.3）、長短腳（左腳短）。

## 5. 變形與長度

- **兩個骨段的部件**：沿用第一階段的「近端 → 遠端」連線混合與體積縮放。
- **三個以上骨段的部件**（例如豎脊肌、腰大肌、腰方肌、腹斜肌）：
  - 轉檔時替每個頂點找出最近的兩個骨段，用的是附著骨頭的取樣點，每塊骨頭 300 點；
  - 兩段距離差 ≥ 3 公分時完全跟最近那段，相等時各半；
  - 每頂點存 3 位元組（兩個骨段序號、第二段權重），網頁直接混合兩段的矩陣，不做體積縮放。
- **轉折點**：端點群組以外的骨段（例如豎脊肌經過的腰椎）各取一個轉折點，取主要跟著該骨段的頂點平均位置，依連線位置排序，太靠兩端（< 5% 或 > 95%）的不要；三角肌仍用第一階段的肌腹轉折點。
- **長度**：起點 → 各轉折點 → 止點的折線長，與中立比較。

### 效能

- 只重算骨段有動到的部件。例如只動肩膀時，一幀約 10 毫秒。
- 法向量與外接球最花時間（全身約 110 毫秒），在動畫、拖動滑桿的過程中先不算，停下 0.12 秒後一次補齊；點選前也會補算。全身動作時每幀約 16–24 毫秒。

## 7. 痠痛點

- **資料**：`tools/parts.js` 的 `tp` 是痠痛點在「近端 → 遠端」連線上的位置（0–1），預設是 0.5，筋膜、肌腱為空。轉檔時在該位置附近一圈頂點中，挑離骨頭最遠（最表淺）的頂點，存成頂點序號。
- **顯示規則**（`painMarkerState`）：
  - 左側「顯示痠痛點」開關關閉時都不顯示。
  - 打開後：姿勢偏離中立時，所有鎖短（橘紅點）、鎖長（藍點）且有計算長度的肌肉自動標出；選取的肌肉若不在鎖短／鎖長狀態，以黃點標示。
  - 隱藏或所在層關閉的肌肉不顯示。
- **位置**：標記是半徑 0.7 公分的小球，跟著頂點位置與法向量浮出 0.5 公分，並隨拆解位移移動。
- **說明卡**：
  - 新增「痠痛點」「轉移痛」兩欄。
  - 姿勢使肌肉鎖短或鎖長時，加一段提示：
    - **鎖短**：容易形成激痛點並轉移痛，以放鬆伸展為主。
    - **鎖長**：痠、緊、拉扯痛，痛處不一定是根源，先放鬆對側鎖短的肌肉。
- **免責**：頁尾與使用說明註明「痠痛點與轉移痛為常見位置，不能取代專業評估」。內容以自己的文字整理常見激痛點描述，不照抄圖譜，**需要專業人員審閱**。

## 9. 中文說明（`content.js`）

- 結構：`window.CONTENT = { muscles, lines, postures, painHints }`，分段以 `Object.assign` 加入，方便用記事本找。
- 每條肌肉的欄位：`name、en、latin、origin、insertion、action、nerve、lines、lockedShort、lockedLong、painPoints、referredPain、notes`。
- 自動測試會檢查：
  - 每個部件都有說明，且沒有多餘的條目；
  - 有痠痛點標記的肌肉，痠痛位置不是「—」；
  - **列車線雙向一致**：軌道上的部件，說明裡都寫了那條線；說明裡寫了某條線，軌道上也一定有它。

不列入的項目與原因（畫面照實顯示，說明卡有註記）：

- **骨盆前傾時的腰大肌、股直肌**：約 −1%。它們的附著點離髖關節轉軸近、力臂短，股直肌又跨過伸直固定的膝；臨床上的「髂腰肌緊」多指久坐造成的適應性縮短與張力。
- **頭前傾時的頭長肌（+3.04%）、骨盆後傾時的股二頭肌長頭（−3.0%）、高低肩時的左提肩胛肌（+3.16%）**：剛好卡在門檻邊緣，避免日後小調整就讓測試忽過忽不過。
- **頭前傾時的頸長肌**：幾何上下頸段前屈使它略縮短（約 −4%）；臨床上說的「深層頸屈肌無力」指肌力，不一定是長度。

## 13. 風險與備援

| 風險 | 備援 |
|---|---|
| 某些肌肉的附著骨頭清單不對，算出不合理的長度變化 | 檢查清單測試只列明確的項目；診斷輸出列出變化最大的部件供人工審閱，不合理的改 `parts.js` 或骨段歸屬（例如舌骨） |
| 多骨段變形在骨段交界處出現折痕 | 調整權重的混合寬度（目前 3 公分） |
| 載入時間變長（`model.js` 約 9.4 MB） | 第一次開啟顯示「模型載入中…」；必要時再降低三角面比例 |
| 痠痛點與轉移痛內容的正確性 | 標示為常見位置，請專業人員審閱後定稿 |
