# 解剖列車 3D

3D 人體肌肉互動網頁：

- **拆解**：一層層關掉淺層、中層肌肉，或單獨隱藏、半透明、拉出某條肌肉，看到深層構造；隱藏的肌肉可以從清單逐條顯示回來。
- **連動**：改變姿勢（圓肩、頭前傾、胸椎駝背、骨盆前傾／後傾、高低肩、長短腳、滑手機、膝過伸、穿高跟鞋、扁平足，或用滑桿自訂，包括彎腰的前彎、側彎、轉向；肩胛、肩關節、手肘、前臂旋轉、手腕、手指、拇指、大腿抬起、膝、踝、足內外翻可分左右，大腿抬起 90° 加膝彎 90° 就是坐姿）時，肌肉跟著骨頭變形，並用顏色標出《解剖列車》概念中的「鎖短」（紅）與「鎖長」（藍）。
- **痠痛點**：可以只標鎖短、鎖長的肌肉，也可以一次顯示**全身痠痛點**（洋紅色菱形，大小代表肌肉的深淺：大＝淺層、小＝深層）；點一下痠痛點，說明卡會寫出那裡「可能的問題」（常見的臨床樣貌與生活習慣背景）、痠痛位置、什麼情況下會鎖短或鎖長、同一條列車線上的其他可疑肌肉，以及鄰近的經脈，**模型上同時把轉移痛可能痛到的區域染在肌肉表面**（128 個區域，邊緣淡出；權重算在中立姿勢的頂點上，所以改姿勢時跟著肌肉走，不花額外效能）；顏色代表痛感覺起來的深度（黃＝表淺、橙＝肌肉層、洋紅紫＝深處），這是痛的深度而不是肌肉的層次。染不到的區域（關節腔、體腔內）才退回用半透明的球標示。
- **找痛源（哪裡痛 → 可能是哪條肌肉）**：打開左側「找痛源」，在模型上點會痛的位置，右側就列出轉移痛會到那裡的肌肉，依「那一點落在它轉移痛範圍的多中心」排序。點後腦會列出枕下肌群，點外踝會列出臀小肌與腓骨肌。
- **姿勢總結（姿勢不良 → 會痛在哪）**：套用姿勢之後，右側列出這個姿勢最吃虧的 10 條肌肉（依長度變化排序），並可以把它們的轉移痛疊起來染在模型上，一眼看出這個姿勢最容易痛的地方。
- **兩種寫法（病人版／臨床版）**：點痠痛點後可以切換讀者。**病人版**只講四件事——為什麼會痛、什麼時候最容易發生、現在可以做的（具體的伸展或訓練，含次數）、什麼情況要看醫生，不出現百分比與解剖術語。**臨床版**給 Δ%、同姿勢下的拮抗肌、這條肌肉在哪些姿勢最吃虧、同區域的鑑別清單、筋膜連鎖，以及由鎖短／鎖長推出的中醫證型與近取、遠取穴。兩邊用的是同一組事實，每一句都由規則組出來——要審閱的是幾十條規則，不是 215 段自由書寫的文字。
- **經脈**：黃帝內經的**十二經脈**加上任脈、督脈，共 14 條，約 200 個常用穴位。經脈綁在骨段上，改變姿勢時跟著身體走；點穴位可以看穴名、代號與定位。另有「穿透顯示」讓經脈與痠痛點不被肌肉擋住。
- **列車線**：選一條或多條《解剖列車》筋膜線，線上的肌肉套上藍色網狀筋膜；改變姿勢時網格跟著拉開或變密，顏色換成鎖短紅、鎖長藍。
- **臉部**：咀嚼肌（顳肌、咬肌、翼內肌、翼外肌）與表情肌（眼輪匝肌、皺眉肌、顴大肌、口輪匝肌、頦肌等）共 25 條，在肌肉清單裡自成「臉部」分區。本模型把頭顱當成一整個骨段，沒有顳顎關節也不做表情，所以這些肌肉不計算長度變化，但可以點選看說明、痠痛點與轉移痛（例如咬肌的痛會轉移到上下排牙齒與耳朵深處）。
- **中文說明**：點選肌肉或從肌肉清單搜尋，顯示起止點、作用、神經、所屬列車線、常見鎖短／鎖長情況與痠痛點。

目前完成第一階段（肩帶）、2A（軀幹、頸、頭皮、下肢）、上肢（前臂、手）、膝、踝、手指關節，以及臉部的咀嚼肌與表情肌：每側 215 個部件、12 條列車線、14 條經脈。足部內在肌、腳趾關節與顳顎關節留到之後。

## 使用

「列車線」「經脈」「姿勢」「圖例」每一區的標題都是收合按鈕，手機與窄畫面預設收起來；寬畫面另外可以用 3D 視窗邊緣的黃色三角形按鈕收起左右兩側的工具列，讓模型佔滿畫面。

線上版：https://vent198022-dotcom.github.io/anatomy-trains-3d/

離線使用：雙擊 `解剖列車網頁/index.html`，用 Chrome 或 Edge 開啟，不需要網路。操作方式見 `解剖列車網頁/使用說明.txt`。

## 修改說明文字

所有中文說明都在 `解剖列車網頁/content.js`，用記事本修改引號內的文字，存檔時選 UTF-8。

## 開發

```bash
npm install
npm run fetch-data   # 下載 Z-Anatomy 原始 FBX 到 data/raw/（約 78 MB，不進 git）
npm run model        # 轉檔 → data/processed/（meta.json、meshes.bin）
npm test             # 單元測試（含 12 個姿勢與上、下肢各關節的鎖短／鎖長檢查清單）
npm run serve        # 本機預覽 http://localhost:8124（修改 src/ 會自動重建；可加 -- --port=8125 換埠）
npm run build        # 產生 解剖列車網頁/app.js 與 model.js（提交前請執行）
```

程式碼在 `src/`（瀏覽器端）與 `tools/`（轉檔），設計見 `docs/superpowers/specs/`。

肌肉說明、痠痛點、轉移痛區域、「可能的問題」與 48 個自我照顧動作是依解剖學教科書、Thomas Myers《解剖列車》與常見激痛點描述自行撰寫的摘要；**自我照顧動作尚未經治療師審閱，有紅旗徵象（夜間痛、外傷後、麻木無力）時不要自行操作**；經脈走向與穴位依常見的經絡學教材整理，座標是依模型骨架估算的教學示意。以上**尚待物理治療師、醫師或中醫師審閱**。

## 注意

教學示意用。長度變化以骨骼幾何計算（起止點距離；跨手肘、手腕、手指、膝、踝的肌肉用力臂乘以轉角），不代表肌肉的活化程度或張力；預設姿勢的幅度刻意比一般人大，讓顏色看得出來。痠痛點與轉移痛為常見位置，範圍因人而異，不能取代專業評估。經脈的穴位座標是估算的教學示意，實際取穴請依標準定位與體表標誌。
